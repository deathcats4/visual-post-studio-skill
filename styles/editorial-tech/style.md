# Editorial Tech — 科技杂志编辑风（可选）

> 视觉样例源于一组已确认风格的多页科普/教程图。仅供学习设计规律，**题材及署名不是模板一部分**。

## Invariants

- 编辑设计：有秩序但不刻板的网格、明确的基线、自然留白和清晰阅读路径。
- 高对比排版：超大主标题 + 清晰副标题 + 较小元信息，避免所有字一个字号。
- 限定色彩职责：基础明暗 + 一种克制强调色；强调色只用于关键词、路径或关键设置。
- 图形逻辑优于装饰：架构图、截图、表格、文件或产品轮廓等主视觉要能解释内容。
- 同一系列保持版面气质、可读性和对齐规律。

## Variants

- 纸白、炭黑、深绿、钴蓝等背景均可；**不强制红黑**。
- 封面：标题主导 / 结构主导 / 强单图。
- 原理：流线架构 / 非对称结构 / 技术剖面。
- 实操：原始UI局部截图 / 特写放大 / 指向性标注。
- 清单：编辑分栏 / 视觉索引 / 强数字对比。
- 总结：结论主导 / 三个抽象元素 / 一句话行动路径。
- 画幅、主题、署名均由当前用户与平台决定。

## Reference palette (optional, NOT fixed)

- warm paper `#F6F4EF`
- charcoal `#17191C`
- accent red-orange `#D64C36`
- grey `#8A8D91`

## Avoid

- 不要把7页做成同一圆角卡片模板。
- 不用虚构的机器人/终端画面冒充技术证据。
- 图片中的 Zotero、Codex、作者署名只是先前案例的**内容**，不是未来生成的风格指令。
- 不重复引用图片中的说明文字到不相关的领域。
