# 案例记录格式

每个新问题单独建一份记录，保留足够信息让下次开发能复现。私有原始材料放在 `personal/`，这里写脱敏定位信息。

```text
ID / 简短名称：
状态：pending / failed / passed
来源：真实用户任务 / 独立审查 / 回归发现
版本 / commit：
日期、宿主和实际使用的工具：
输入、已有授权与本次范围：
最小复现步骤：
实际结果与证据位置：
期望结果：
判断：确定的原因 / 推测 / 未知分别写明
改动文件与理由：
自动回归：测试名称、运行结果；不适用时写明
实际视觉验收：图片、具体缺陷、复验结果；未执行写 pending
相邻场景是否受影响：
剩余问题与下一步：
```
