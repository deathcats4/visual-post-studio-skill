# Tool Routing — 能力决策矩阵

| 场景 | 首选 | 风险/替代 |
|---|---|---|
| 新封面、插画、视觉海报、含字信息页 | 可用的 image generation 模型直接生成完整图页 | 无该工具时只产出精确提示词，勿伪造图片；不要默认用代码给生好的底图排字 |
| 现有图修改颜色、增删对象、局部重构 | image editing 模型 | 让用户确认改动区域、保留其余区域 |
| 软件教程真实截图 | 真实截图作为素材，由 image editing 模型设计完整图页 | 不得假造菜单与运行结果；编辑后核查每个标签；无法保真时说明缺口 |
| 细密代码/公式/表格/文献字段 | image generation/editing 模型；必要时先精简为关键字段 | 用真实来源图保留必须逐字准确的内容；受控排版须有明确必要性并先获用户同意 |
| 分镜/文案/参考图分析 | 语言与视觉理解 | 不需要也不应强制生图 |
| 精确像素检查 | 可用文件工具/Python | 没有实际文件不假称已检验 |
| 发布到社交平台 | 用户显式授权 + 客户端支持 | 基础 Skill 不负责账号登录或自动发布 |

工具名不绑定厂商。`image_gen` 是一种可用工具示例，不代表每个 Agent 都已配置。规范约束的是 **行为与验收**，不能保证不存在的工具自动出现。

### 降级层级

1. 可以生图 → 按页独立生成并验证。
2. 不能生图，但可以渲染HTML/SVG → 仅在用户接受受控渲染时采用，并清楚说明它是程序排版成图，不是生成模型生图。
3. 只有文本工具 → 提供准确的分镜+页面 prompts+可复用风格卡，明确没有真正交付图片。
4. 用户只要文字 → 不进行任何生图操作。
