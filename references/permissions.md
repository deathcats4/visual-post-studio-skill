# Permissions, Privacy and Redistribution

Public core skill should contain no login credentials, private screenshots, identifiable personal info, account tokens, internal links, or proprietary reports.

Reference images may be supplied by users or derived from the user's own creations. Distinguish **allowed to use for this task** from **licensed for public redistribution**. The latter must not be presumed; require confirmation before bundling third-party imagery into public skill repositories.

Do not copy watermark, distinctive character, registered logos, exact layout, or a reference creator's signature into new unrelated works by accident. Record rights and usage constraints in `attribution.md`.

When a screenshot shows personal files, account details, messages or private data, use targeted cropping or redaction **without changing actual UI operation steps**. Do not move a privately provided screenshot into an open example package by default.

The example images bundled in `styles/editorial-tech/examples` are optional visual references and may show a specific author's signature and original subject. Do not treat these as branding defaults or real software documentation. Review `styles/editorial-tech/attribution.md` before public distribution. The MIT license on Skill text/scripts does not by itself grant rights to external images or trademarks.

## 网络检索的样例与模板

公开可观看的案例属于**参考来源**，不自动取得二次创作、商用、下载或再分发权。在线发现的案例，优先保存URL和自创的风格卡，不在公开发行的ZIP里混入第三方图片。对于真正可编辑的模板，必须核实资源格式、许可、访问及可能的付费条件。不得绕过站点访问控制或运行未经验证的第三方脚本。
