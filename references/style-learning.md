# Style Learning — 从参考图提炼可复用设计语言

## 可学习，不是权重训练

读取用户提供的1–N张图片并观察：

1. **大形状**：主体落点、网格、留白、视觉重心、画面节奏；
2. **文字层级**：中文和英文的相对大小、粗细、字距、行距、对齐；
3. **颜色逻辑**：底色、主字色、强调色，以及颜色在不同页的职责；
4. **视觉媒介**：照片/插画/矢量图/UI截屏/贴纸/纸纹/材质；
5. **信息密度**：封面与正文、轻页与重页之间的分配；
6. **变化空间**：哪些必须保持、哪些允许不同构图、配色和图像比例。

引用 `templates/style-card.md` 保存以下两类条款：

- **Invariants (必须保持)**：例如标题有明确层级、色彩克制、网格精确。
- **Variants (可以变化)**：具体主色、每页构图、页数、图形主题、受众身份。

不要把图里出现的主题词（例如某软件名称）、作者署名、私有账号 ID、品牌 logo 错误当成风格规则。借鉴抽象设计原则，生成新颖的独立版式，不复制他人的整张版面及独特插画。

## 先自主寻找风格参考（如用户允许）

不必等待用户上传图片。用户要求“自己去找模板”时，调用实际可用的网页/图片搜索，阅读 `references/style-discovery.md`，对找到的公开案例抽取设计原则，并记录真实URL、检索状态和许可边界。浏览不可用时坦承无法联网，不能虚构来源。

## 风格路由

- `auto`：根据受众、题材和目的提出一种默认视觉方向（或两种明显不同方案供选）；在获用户允许且有搜索工具时，可以先在线寻找参考。
- `discover-online`：按 `references/style-discovery.md` 自主搜索2–3种真实设计方向，生成独立风格卡，不自动复制受版权保护的参考作品。
- `preset:<id>`：读取 `styles/<id>/style.md`；如有授权参考图，视觉生成时可引用。
- `reference-images`：用户上传参考图；立即提炼新的 style card；无需先开发新的 Skill。
- `custom`：尊重用户提供的任意规范，如全黑白、照片实拍、卡通水彩等。

当不同参考图之间矛盾时，指出差异并按用户偏好综合：比如采用图1排版、图2色调，或各自做A/B方案。不要含糊声称“完全学到了”。

## 保存新风格包

建议目录：

```text
styles/my-style/
  style.md         # 可给AI阅读的视觉规范
  style.json       # 可选结构参数
  examples/        # 获许可的参考图片
  attribution.md   # 来源、许可、是否可公开分享
```

个人上传图片默认只用于当前会话/项目，不默认放入公共仓库。分享给社区必须检查许可、隐私和水印等约束。

对含软件界面的图，不允许把假 UI 的外观当作真实使用教程的依据。
