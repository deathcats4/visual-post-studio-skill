# Derived style: Editorial Urban (由编辑风参考图抽象迁移)

## Invariants

- 巨幅标题与清晰小字对比。
- 12列或相似规则网格，具有对齐秩序与充足留白。
- 暖浅背景与一种强调色，颜色用于指示重点。
- 精准的标注线与页码，避免通用杂乱卡片。

## Variants

- 题材变更为城市散步，使用街景/建筑/地图信息，而不是软件图标和“Zotero”关键词。
- 页面可采用全幅摄影或分栏杂志，不按旧图复制节点与箭头。
- 新作者独立选择署名，默认不附旧作者名字。
