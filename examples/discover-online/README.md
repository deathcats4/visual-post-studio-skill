# Example E: 用户让 Agent 自己找模板

用户：“我没有设计参考，你自己上网找一些好看的风格，帮我做一篇4页的城市通勤省时技巧图文。直接做。”

1. `mode=discover` + `deliverable=images`，不将某个科技杂志预设当默认模板。
2. 确认运行环境是否能网页/图片搜索。若能，搜索中文与英文相关关键词，例如“通勤 效率 小红书 图文排版”“editorial lifestyle infographic carousel”“commute checklist layout”。
3. 收集3–6条**真实**参考链接，分类：标题主导 / 图解地图感 / 编辑摄影风。未检索到的不要编造。
4. 对可见候选比较：封面辨识度、内页信息密度、跨四页延展能力、手机可读性与版权风险。
5. 因用户说“直接做”，自动选适合的方案，写入 `templates/discovery-shortlist.md` 对应记录，提炼原创 style card。无需强制等待审批。
6. 分镜后每一页独立调用实际生图工具，绝不拼四页大图。每页针对内容选择不同布局。
7. 输出四张图、标题和配文，记录视觉参考来源URL；不将搜索到的第三方图片加入公开 Skill 发行包。

若没有联网工具：明确“本次无法自主联网搜索模板”，可从本地风格、上传样图、自主原创风格中继续创作；**不能伪称已在线调研**。

若用户改口“要可编辑 Canva 模板”：把 `deliverable` 切换为 `editable-template`，只推荐能核实格式、访问权限和许可证的真实模板，不能拿 AI 生出的 PNG 冒充可编辑文件。
